- Several specific dates per alarm, across any months: "Dates" list with "+ Add date" (calendar), each date shown as a
  removable chip. The alarm rings only on those dates (no weekly repetition), each date once; passed dates drop out;
  when the last one has passed the alarm switches off.
- Clear choice on the alarm page between: Once · Weekly days · Specific dates.
- Helper pop-up when a day circle is tapped or a date is picked: says what the alarm will now do (e.g. "Rings every
  Thursday from Thu 26 Nov") and how to get another repetition (once: deselect the days; several dates: Specific
  dates). Closes by itself after 3 s (stays if touched).
- Alarm clock settings: "Helpers" on/off switch for these pop-ups.
- Helper wording: "One time only: use only the Date button, don't select any day disk." / "Repeated alarm: choose the
  start date on the calendar and the day buttons here." / "Several dates: choose specific dates on the monthly
  calendar." Specific dates are picked on a monthly calendar (tap several days, move between months).

## Alarms in the phone's calendar (requested 2026-11-19 12:54)
- Alarm clock settings: "Show alarms in my calendar" on/off. Uses Android's own calendar on the phone (the account
  already signed in, e.g. Google): no account details typed or stored by the app — only Android's calendar
  permission is asked, then the calendar to use is picked from the list (the main account pre-selected).
- Each alarm becomes a calendar event at its time: weekly alarms as one repeating event (from the start date),
  one-time / specific dates as single events; name = alarm name (or "Alarm 07:00"). No calendar reminders (the app
  rings). Events are updated / removed when the alarm changes or is deleted; switching the option off removes them.
